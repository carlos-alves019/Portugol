# Repositório: portugol-projects

# 🇵🇹 Descrição
Projetos e exercícios desenvolvidos em Portugol, focados em lógica de programação,
estrutura sequencial, decisões, repetições e resolução de problemas básicos.
Este repositório serve como base de aprendizagem para reforçar os fundamentos
da programação antes de avançar para linguagens mais complexas.

# 🇵🇹 Tecnologias Utilizadas
- Portugol Studio
- Visualg 

# 🇵🇹 Funcionalidades
- Exercícios básicos e intermediários
- Estruturas sequenciais
- Estruturas condicionais (se / senao)
- Estruturas de repetição (para, enquanto, repita)
- Vetores e matrizes simples
- Algoritmos de treino lógico
